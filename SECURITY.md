# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately through [GitHub private vulnerability reporting](https://github.com/sitien173/scene-flow/security/advisories/new). Include the affected file, steps to reproduce, and the impact you expect.

You should get a first response within 7 days. Fixes ship in a new release, and the advisory is published after the fix.

## Scope

In scope: the scene-flow skill under `skills/scene-flow/`, its scripts, templates, and the plugin manifests.

Out of scope: the bundled third-party skills listed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Report those to their upstream projects. scene-flow ships them unmodified and updates them when upstream releases a fix.
